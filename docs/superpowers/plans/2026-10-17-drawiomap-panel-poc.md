# simnv-drawiomap-panel PoC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Grafana panel plugin that shows a draw.io diagram as a network weathermap: links coloured by traffic per direction, shapes coloured by state, sparklines, click-to-link, and the real draw.io editor in a modal.

**Architecture:** The panel stores the draw.io XML and the draw.io-exported SVG in panel options. View mode inserts the SVG once, indexes cells by `data-cell-id` and `data-meta-*`, computes patches with a pure binding engine from the panel queries, and writes styles into the SVG DOM plus an overlay `<g>` for half-links, labels and sparklines. Edit mode opens draw.io in embed mode inside an iframe modal and stores `{xml, svg}` on save. No draw.io code runs in view mode.

**Tech Stack:** `@grafana/create-plugin` 7.13.0, `@grafana/{data,ui,runtime,schema}` 12.4.x, React 18.3 types (runtime React comes from Grafana), TypeScript, Vitest + jsdom, Playwright + `@grafana/plugin-e2e` 3.15.x, `zod`, `js-yaml`, Docker Compose (Grafana 12.4.13, Grafana 13.2.4, `jgraph/drawio` 32.4.1, VictoriaMetrics, a Python metrics generator).

**Spec:** `docs/superpowers/specs/2026-10-17-drawiomap-panel-poc-design.md`. Research: `docs/research/grafana-drawio-plugin.md`, `docs/research/reference-projects.md`. Contract: `docs/research/portograph-contract.md` (schema 1; copy of portograph `docs/drawio-binding-contract.md`). Fixture sources: `fixtures/portograph/{l1-physical,l2-link,l3-routing,l4-exits}.drawio` (+ `.yaml`), already committed.

## Global Constraints

- Plugin id: `simnv-drawiomap-panel`. Type: `panel`. `dependencies.grafanaDependency: ">=12.4.0"`.
- Build against `@grafana/data`, `@grafana/ui`, `@grafana/runtime`, `@grafana/schema` at the latest `12.4.x`. `react`, `react-dom` `18.3.x`, `@types/react`, `@types/react-dom` `18.3.x`. Do not bundle React. No React 19-only APIs. No `findDOMNode`, string refs, `defaultProps` on function components.
- Do not import `Graph`, `GraphWithLegend`, `GraphContextMenu`, `GraphSeriesToggler` from `@grafana/ui`. Do not use `config.apps` / `config.panels` from `@grafana/runtime`.
- View mode must load no draw.io scripts: no `mxgraph`, no `maxgraph`, no `viewer-static`, no iframe outside the editor modal.
- Sanitise every SVG with DOMPurify (`svg`, `svgFilters`, `html` profiles) plus the structural pass in `src/render/sanitize.ts`. Keep `data-cell-id` and `data-meta-*`. No `iframe`, `object`, `embed`, `script`, external `<use>`, or CSS `url()` to external resources.
- Recolour SVG elements through `element.style.fill` / `element.style.stroke` / `element.style.strokeWidth`, never through the `fill` / `stroke` attributes (draw.io emits a `style` attribute that wins).
- A missing series renders grey "no data" (`theme.colors.text.disabled`), never green.
- Unsigned plugin. Grafana loads it with `GF_PLUGINS_ALLOW_LOADING_UNSIGNED_PLUGINS=simnv-drawiomap-panel`.
- All CSS classes and data attributes that the plugin adds use the prefix `dmap-` / `data-dmap-`.
- Unit tests: Vitest with jsdom (`npm test` runs `vitest run`). E2E: Playwright with `@grafana/plugin-e2e`.
- Commit messages: Conventional Commits (`feat:`, `test:`, `chore:`, `docs:`). No `Co-Authored-By` lines. Never commit secrets.
- Writing style for all text (docs, comments, UI copy): ASD-STE100 Simplified Technical English. Short sentences. One instruction per sentence. Active voice.
- Workers in one wave run in parallel in the same git checkout. A task must only create or modify the files listed under its **Files** heading. Run `git add <own files>` only, never `git add -A`.
- Every task ends with: `npm run typecheck && npm run lint && npm test` green for the files it owns, then a commit.

```ts
import type { DataFrame, DisplayValue, Field, GrafanaTheme2, ScopedVars, ThresholdsConfig } from '@grafana/data';

/* ---------- cells (from the SVG) ---------- */

export type CellKind = 'node' | 'port' | 'link' | 'link-label' | 'other';

/** One end of a link, parsed from pg-from / pg-to ("node", "node:port", "node:port#2"). */
export interface Endpoint {
  node: string;
  port?: string;
  ordinal: number;
  raw: string;
}

/** Pure description of one SVG cell group. No DOM references. */
export interface CellMeta {
  /** data-cell-id */
  id: string;
  kind: CellKind;
  /** pg-id when present, else id */
  key: string;
  /** data-meta-* attributes without the prefix, e.g. { 'pg-kind': 'link', capacity: '1000000000' } */
  attrs: Record<string, string>;
  /** Visible label text. For a link: the text of its link-label cell (pg-of), else its own label. */
  labelText: string;
  isEdge: boolean;
  from?: Endpoint;
  to?: Endpoint;
}

export interface CellEntry {
  meta: CellMeta;
  group: SVGGElement;
  /** First shape primitive of a vertex (rect|path|ellipse|polygon|image) outside the label group. */
  shape?: SVGGraphicsElement;
  /** Edge polyline: first path with fill="none". */
  line?: SVGPathElement;
  /** Edge arrow heads: later paths with pointer-events="all". */
  arrows: SVGPathElement[];
  /** Text or foreignObject label element. */
  label?: Element;
  original: { fill?: string; stroke?: string; strokeWidth?: string; text?: string };
}

/** Keyed by cell id (data-cell-id). */
export type CellIndex = Map<string, CellEntry>;

/* ---------- series (from panel data) ---------- */

export interface SeriesInfo {
  refId?: string;
  name: string;
  labels: Record<string, string>;
  values: number[];
  times?: number[];
  field: Field;
  frame: DataFrame;
}

/* ---------- panel options ---------- */

export interface Diagram {
  xml: string;
  svg: string;
  hash: string;
  updatedAt: string;
}

export type ZoomMode = 'fit' | 'fit-width' | 'original' | 'custom';

export interface ZoomOptions {
  mode: ZoomMode;
  percent: number;
  wheel: boolean;
  pan: boolean;
}

export interface Options {
  diagram?: Diagram;
  rules: Rule[];
  editorUrl: string;
  zoom: ZoomOptions;
  linkWidth: { min: number; max: number };
}

export const DEFAULT_OPTIONS: Options = {
  rules: [],
  editorUrl: 'http://localhost:8080',
  zoom: { mode: 'fit', percent: 100, wheel: false, pan: false },
  linkWidth: { min: 2, max: 10 },
};

/* ---------- rules ---------- */

/** Exact string, or /regex/ (JS regex between slashes, optional flags). */
export type Matcher = string;

export interface SeriesSelector {
  refId?: string;
  name?: Matcher;
  match?: Record<string, Matcher>;
}

export interface CellSelector {
  /** cell ids or pg-ids */
  ids?: string[];
  kind?: CellKind | 'any';
  attrs?: Record<string, Matcher>;
  label?: Matcher;
  /** link between two node ids, any direction */
  between?: [string, string];
}

export type ReducerName = 'last' | 'mean' | 'max' | 'min';

export interface RuleThresholds {
  mode: 'percent' | 'absolute';
  /** [threshold, colour name or hex], ascending */
  steps: Array<[number, string]>;
}

export interface LinkRule {
  a2b?: SeriesSelector;
  b2a?: SeriesSelector;
  /** bit/s; number or template like "${cell.capacity}" */
  capacity?: string | number;
}

export type SparklinePosition = 'bottom' | 'top' | 'inside';

export interface SparklineRule extends SeriesSelector {
  position?: SparklinePosition;
}

export interface ShapeRule {
  series?: SeriesSelector;
  fill?: boolean;
  stroke?: boolean;
  text?: boolean;
  sparkline?: SparklineRule;
}

export interface Rule {
  name: string;
  select: CellSelector;
  link?: LinkRule;
  shape?: ShapeRule;
  reducer?: ReducerName;
  /** label template; default "${value} · ${percent}" for links, "${value}" for shapes */
  label?: string;
  thresholds?: RuleThresholds;
  url?: string;
}

/* ---------- binding output ---------- */

export type BindStatus = 'ok' | 'nodata' | 'unbound';

export interface TemplateScope {
  cell: Record<string, string>;
  from?: Record<string, string>;
  to?: Record<string, string>;
  labels?: Record<string, string>;
  value?: string;
  percent?: string;
}

export interface HalfState {
  status: BindStatus;
  color: string;
  width: number;
  label: string;
  /** index into the threshold steps that produced the colour; -1 when no data */
  stepIndex: number;
  value?: number;
  percent?: number;
  display?: DisplayValue;
  series?: SeriesInfo;
}

export interface ShapeState {
  status: BindStatus;
  color: string;
  fill: boolean;
  stroke: boolean;
  stepIndex: number;
  text?: string;
  value?: number;
  display?: DisplayValue;
  series?: SeriesInfo;
}

export interface SparklineState {
  values: number[];
  color: string;
  position: SparklinePosition;
  series?: SeriesInfo;
}

export interface LinkTarget {
  title: string;
  url: string;
}

export interface CellPatch {
  cellId: string;
  ruleNames: string[];
  scope: TemplateScope;
  link?: { a2b?: HalfState; b2a?: HalfState };
  shape?: ShapeState;
  sparkline?: SparklineState;
  /** rule url(s) after template resolution; dashboard variables are resolved later by replaceVariables */
  urls: LinkTarget[];
  warnings: string[];
}

export type PatchMap = Map<string, CellPatch>;

export interface BindContext {
  theme: GrafanaTheme2;
  fieldThresholds?: ThresholdsConfig;
```

```ts
/** FNV-1a 32-bit hash of a UTF-16 string, as 8 lowercase hex chars. Good enough to memoise an SVG. */
export function fnv1a(text: string): string {
  let h = 0x811c9dc5;
  for (let i = 0; i < text.length; i++) {
    h ^= text.charCodeAt(i);
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h.toString(16).padStart(8, '0');
}
```

```ts
import yaml from 'js-yaml';
import type { Rule } from '../types';

const matcher = z.string();
const seriesSelector = z
  .object({ refId: z.string().optional(), name: matcher.optional(), match: z.record(matcher).optional() })
  .strict();
const cellSelector = z
  .object({
    ids: z.array(z.string()).optional(),
    kind: z.enum(['node', 'port', 'link', 'link-label', 'other', 'any']).optional(),
    attrs: z.record(matcher).optional(),
    label: matcher.optional(),
    between: z.tuple([z.string(), z.string()]).optional(),
  })
  .strict();
const thresholds = z
  .object({ mode: z.enum(['percent', 'absolute']), steps: z.array(z.tuple([z.number(), z.string()])).min(1) })
  .strict();

export const ruleSchema = z
  .object({
    name: z.string().min(1),
    select: cellSelector,
    link: z
      .object({
        a2b: seriesSelector.optional(),
        b2a: seriesSelector.optional(),
        capacity: z.union([z.string(), z.number()]).optional(),
      })
      .strict()
      .optional(),
    shape: z
      .object({
        series: seriesSelector.optional(),
        fill: z.boolean().optional(),
        stroke: z.boolean().optional(),
        text: z.boolean().optional(),
        sparkline: seriesSelector.extend({ position: z.enum(['bottom', 'top', 'inside']).optional() }).strict().optional(),
      })
      .strict()
      .optional(),
    reducer: z.enum(['last', 'mean', 'max', 'min']).optional(),
    label: z.string().optional(),
    thresholds: thresholds.optional(),
    url: z.string().optional(),
  })
  .strict();

export const rulesSchema = z.array(ruleSchema);

export interface ParseResult {
  rules?: Rule[];
  errors: string[];
}

export function parseRules(input: unknown): ParseResult {
  const res = rulesSchema.safeParse(input ?? []);
  if (res.success) {
    return { rules: res.data as Rule[], errors: [] };
  }
  const errors = res.error.issues.map((i) => {
    const path = i.path.map((p) => (typeof p === 'number' ? `[${p}]` : `.${p}`)).join('').replace(/^\./, '');
    return `${path || '(root)'}: ${i.message}`;
  });
  return { errors };
}

export function parseRulesYaml(text: string): ParseResult {
  let doc: unknown;
  try {
    // js-yaml 4: load() is the former safeLoad(); it builds plain data only, no custom types.
    doc = yaml.load(text);
  } catch (e) {
    return { errors: [`YAML: ${(e as Error).message}`] };
  }
  if (doc === undefined || doc === null) {
    return { rules: [], errors: [] };
  }
  return parseRules(doc);
}

export function rulesToYaml(rules: Rule[]): string {
  return yaml.dump(rules, { noRefs: true, lineWidth: 120, quotingType: '"' });
}
```

```ts
/**
 * The only module that knows the portograph draw.io binding contract (schema 1).
 * See docs/research/portograph-contract.md. Adjust here when the contract changes.
 */
import type { CellKind, CellMeta, Endpoint } from '../types';

export const PG_KINDS: Record<string, CellKind> = {
  node: 'node',
  port: 'port',
  link: 'link',
  'link-label': 'link-label',
};

/** "node", "node:port" or "node:port#n". */
export function parseEndpoint(raw: string): Endpoint {
  const colon = raw.indexOf(':');
  if (colon < 0) {
    return { node: raw, port: undefined, ordinal: 1, raw };
  }
  const node = raw.slice(0, colon);
  let port = raw.slice(colon + 1);
  let ordinal = 1;
  const hash = port.lastIndexOf('#');
  if (hash >= 0 && /^\d+$/.test(port.slice(hash + 1))) {
    ordinal = Number(port.slice(hash + 1));
    port = port.slice(0, hash);
  }
  return { node, port, ordinal, raw };
}

/** Strip HTML tags from a draw.io label attribute. */
export function plainLabel(html: string | undefined): string {
  if (!html) {
    return '';
  }
  return html
    .replace(/<br\s*\/?>/gi, '\n')
    .replace(/<\/div>\s*<div/gi, '</div>\n<div')
    .replace(/<[^>]+>/g, '')
    .replace(/&nbsp;/g, ' ')
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&quot;/g, '"')
    .replace(/&amp;/g, '&')
    .trim();
}

/**
 * Build the pure cell description from the SVG group attributes.
 * @param id       data-cell-id
 * @param attrs    data-meta-* attributes without the prefix (label, pg-kind, ...)
 * @param isEdge   true when the group holds an edge polyline
 * @param labelText visible text found in the SVG (preferred over attrs.label)
 */
export function cellMetaFromAttrs(id: string, attrs: Record<string, string>, isEdge: boolean, labelText?: string): CellMeta {
  const kind: CellKind = PG_KINDS[attrs['pg-kind'] ?? ''] ?? 'other';
  const key = attrs['pg-id'] ?? id;
  const meta: CellMeta = {
    id,
    kind,
    key,
    attrs: { ...attrs },
    labelText: labelText ?? plainLabel(attrs.label),
    isEdge,
  };
  if (attrs['pg-from']) {
    meta.from = parseEndpoint(attrs['pg-from']);
  }
  if (attrs['pg-to']) {
    meta.to = parseEndpoint(attrs['pg-to']);
  }
  return meta;
}

/** A link's label lives in a separate cell with pg-of. Copy its text onto the link. */
export function attachLinkLabels(cells: CellMeta[]): CellMeta[] {
  const byKey = new Map(cells.filter((c) => c.kind === 'link').map((c) => [c.key, c]));
  for (const c of cells) {
    if (c.kind === 'link-label' && c.attrs['pg-of']) {
      const link = byKey.get(c.attrs['pg-of']);
      if (link && c.labelText) {
        link.labelText = c.labelText;
      }
    }
  }
  return cells;
}

/** Scope values for templates: ${cell.*}, ${from.*}, ${to.*}. */
export function endpointScope(e?: Endpoint): Record<string, string> | undefined {
  if (!e) {
    return undefined;
  }
  return { node: e.node, port: e.port ?? '', ordinal: String(e.ordinal), raw: e.raw };
}
```

```python
"""Push synthetic node_exporter-like series to VictoriaMetrics every 5 s.

Stdlib only. Counters grow at a constant rate from process start, so
rate(...[1m]) * 8 is stable: isp-a 41 Mb/s (41 % of 100M), radio 90 Mb/s
(90 % of 100M), br-lan 480 Mb/s (48 % of 1G). lte has no traffic series and up=0.
"""
import math
import os
import time
import urllib.request

VM = os.environ.get("VM_URL", "http://victoriametrics:8428")

# (job, device, transmit bytes/s, receive bytes/s)
LINKS = [
    ("node-net-a", "lan", 60_000_000, 12_000_000),
    ("node-rtr-a", "br-lan", 60_000_000, 12_000_000),
    ("node-net-b", "lan", 2_500_000, 1_000_000),
    ("node-rtr-b", "br-lan", 2_500_000, 1_000_000),
    ("node-isp-a", "pppoe", 5_125_000, 1_250_000),
    ("node-rtr-a", "wan1", 1_250_000, 5_125_000),
    ("node-radio", "dhcp", 11_250_000, 2_000_000),
    ("node-rtr-a", "wan2", 2_000_000, 11_250_000),
    ("node-isp-b", "pppoe", 3_000_000, 500_000),
    ("node-rtr-b", "pppoe", 500_000, 3_000_000),
    ("node-rtr-a", "ts0", 400_000, 300_000),
    ("node-rtr-b", "ts0", 300_000, 400_000),
    ("node-rtr-a", "tun0", 200_000, 100_000),
    ("node-proxy-a", "tun-in", 100_000, 200_000),
    ("node-rtr-b", "tun0", 150_000, 90_000),
    ("node-proxy-b", "tun-in", 90_000, 150_000),
    ("node-proxy-a", "relay-out", 50_000, 20_000),
    ("node-proxy-b", "chain-in", 20_000, 50_000),
]
UP = {
    "node-net-a": 1, "node-net-b": 1, "node-rtr-a": 1, "node-rtr-b": 1,
    "node-isp-a": 1, "node-radio": 1, "node-lte": 0, "node-isp-b": 1,
    "node-proxy-a": 1, "node-proxy-b": 1,
}


def build(elapsed: float) -> bytes:
    lines = []
    for job, dev, tx, rx in LINKS:
        lines.append(f'node_network_transmit_bytes_total{{job="{job}",device="{dev}"}} {int(tx * elapsed)}')
        lines.append(f'node_network_receive_bytes_total{{job="{job}",device="{dev}"}} {int(rx * elapsed)}')
    for i, (job, up) in enumerate(UP.items()):
        lines.append(f'up{{job="{job}"}} {up}')
        load = 1.0 + 0.8 * math.sin(elapsed / 60.0 + i)
        lines.append(f'node_load1{{job="{job}"}} {load:.3f}')
    return ("\n".join(lines) + "\n").encode()


def main() -> None:
    t0 = time.time()
    while True:
        body = build(time.time() - t0)
        req = urllib.request.Request(f"{VM}/api/v1/import/prometheus", data=body, method="POST")
        try:
            urllib.request.urlopen(req, timeout=5).read()
        except Exception as exc:  # noqa: BLE001
            print(f"push failed: {exc}", flush=True)
        time.sleep(5)


if __name__ == "__main__":
    main()
```

```ts
import type { TemplateScope } from '../types';

const PLACEHOLDER = /\$\{([a-zA-Z_][\w]*)(?:\.([^}:]+))?\}/g;
const SCOPE_ROOTS = new Set(['cell', 'from', 'to', 'labels', 'value', 'percent']);

export interface ResolveResult {
  text: string;
  unresolved: string[];
}

/**
 * Replaces ${cell.x}, ${from.x}, ${to.x}, ${labels.x}, ${value}, ${percent}.
 * Unknown roots (dashboard variables such as ${__url_time_range}) stay as they are and are not reported.
 */
export function resolveTemplate(tpl: string, scope: TemplateScope): ResolveResult {
  const unresolved: string[] = [];
  const text = tpl.replace(PLACEHOLDER, (whole, root: string, path: string | undefined) => {
    if (!SCOPE_ROOTS.has(root)) {
      return whole;
    }
    if (root === 'value' || root === 'percent') {
      const v = scope[root];
      if (v === undefined) {
        unresolved.push(root);
        return whole;
      }
      return v;
    }
    const obj = scope[root as 'cell' | 'from' | 'to' | 'labels'];
    const key = path ?? '';
    const v = obj?.[key];
    if (v === undefined) {
      unresolved.push(`${root}.${key}`);
      return whole;
    }
    return v;
  });
  return { text, unresolved };
}
```

```ts
import type { CellMeta, CellSelector, Matcher } from '../types';

const cache = new Map<string, (v: string) => boolean>();

/** "/re/flags" becomes a RegExp test; any other string is an exact match. */
export function compileMatcher(m: Matcher): (v: string) => boolean {
  let fn = cache.get(m);
  if (fn) {
    return fn;
  }
  const re = /^\/(.+)\/([a-z]*)$/.exec(m);
  if (re) {
    const rx = new RegExp(re[1], re[2]);
    fn = (v) => rx.test(v);
  } else {
    fn = (v) => v === m;
  }
  cache.set(m, fn);
  return fn;
}

export function cellMatches(sel: CellSelector, c: CellMeta): boolean {
  if (sel.ids && !sel.ids.includes(c.id) && !sel.ids.includes(c.key)) {
    return false;
  }
  if (sel.kind && sel.kind !== 'any' && sel.kind !== c.kind) {
    return false;
  }
  if (sel.attrs) {
    for (const [k, m] of Object.entries(sel.attrs)) {
      const v = c.attrs[k];
      if (v === undefined || !compileMatcher(m)(v)) {
        return false;
      }
    }
  }
  if (sel.label && !compileMatcher(sel.label)(c.labelText)) {
    return false;
  }
  if (sel.between) {
    const [a, b] = sel.between;
    const f = c.from?.node;
    const t = c.to?.node;
    if (!f || !t) {
      return false;
    }
    if (!((f === a && t === b) || (f === b && t === a))) {
      return false;
    }
  }
  return true;
}

export function selectCells(sel: CellSelector, cells: CellMeta[]): CellMeta[] {
  return cells.filter((c) => cellMatches(sel, c));
}
```

```ts
import { FieldType, getFieldDisplayName } from '@grafana/data';
import type { DataFrame } from '@grafana/data';
import type { SeriesInfo, SeriesSelector, TemplateScope } from '../types';
import { compileMatcher } from './select';
import { resolveTemplate } from './template';

export function extractSeries(frames: DataFrame[]): SeriesInfo[] {
  const out: SeriesInfo[] = [];
  for (const frame of frames) {
    const timeField = frame.fields.find((f) => f.type === FieldType.time);
    const times = timeField ? (timeField.values as number[]) : undefined;
    for (const field of frame.fields) {
      if (field.type !== FieldType.number) {
        continue;
      }
      out.push({
        refId: frame.refId,
        name: getFieldDisplayName(field, frame, frames),
        labels: field.labels ?? {},
        values: field.values as number[],
        times,
        field,
        frame,
      });
    }
  }
  return out;
}

export interface FindResult {
  series?: SeriesInfo;
  unresolved: string[];
}

/** First series that satisfies refId, name and every label matcher. Templates resolve against scope first. */
export function findSeries(sel: SeriesSelector, series: SeriesInfo[], scope: TemplateScope): FindResult {
  const unresolved: string[] = [];
  const labelTests: Array<[string, (v: string) => boolean]> = [];
  for (const [k, tpl] of Object.entries(sel.match ?? {})) {
    const r = resolveTemplate(tpl, scope);
    unresolved.push(...r.unresolved);
    labelTests.push([k, compileMatcher(r.text)]);
  }
  let nameTest: ((v: string) => boolean) | undefined;
  if (sel.name) {
    const r = resolveTemplate(sel.name, scope);
    unresolved.push(...r.unresolved);
    nameTest = compileMatcher(r.text);
  }
  if (unresolved.length) {
    return { unresolved };
  }
  const hit = series.find((s) => {
    if (sel.refId && s.refId !== sel.refId) {
      return false;
    }
    if (nameTest && !nameTest(s.name)) {
      return false;
    }
    return labelTests.every(([k, test]) => s.labels[k] !== undefined && test(s.labels[k]));
  });
  return { series: hit, unresolved };
}
```

```ts
import type { ReducerName } from '../types';

export function reduceValues(values: number[], reducer: ReducerName): number | undefined {
  const nums = values.filter((v) => typeof v === 'number' && Number.isFinite(v));
  if (!nums.length) {
    return undefined;
  }
  switch (reducer) {
    case 'last':
      return nums[nums.length - 1];
    case 'mean':
      return nums.reduce((a, b) => a + b, 0) / nums.length;
    case 'max':
      return Math.max(...nums);
    case 'min':
      return Math.min(...nums);
  }
}
```

```ts
// src/binding/color.ts
import type { DisplayValue, GrafanaTheme2, ThresholdsConfig } from '@grafana/data';
import type { RuleThresholds } from '../types';

export interface ColorResult {
  color: string;
  stepIndex: number;
}

/** Used for percent-of-capacity colouring when the rule sets no thresholds. */
export const DEFAULT_PERCENT_STEPS: Array<[number, string]> = [
  [0, 'green'],
  [60, 'yellow'],
  [85, 'red'],
];

export function noDataColor(theme: GrafanaTheme2): string {
  return theme.colors.text.disabled;
}

/** Index of the last step whose threshold is <= input (steps ascending). */
export function stepIndexOf(input: number, steps: Array<[number, string]>): number {
  let idx = -1;
  for (let i = 0; i < steps.length; i++) {
    if (input >= steps[i][0]) {
      idx = i;
    }
  }
  return Math.max(0, idx);
}

function fieldSteps(t: ThresholdsConfig | undefined): Array<[number, string]> | undefined {
  if (!t?.steps?.length) {
    return undefined;
  }
  return t.steps.map((s) => [s.value === null || s.value === undefined ? -Infinity : s.value, s.color]);
}

/**
 * Precedence:
 * 1. rule thresholds: percent mode applies to `percent` (0..100), absolute mode to `value`;
 * 2. a capacity exists (percent defined): DEFAULT_PERCENT_STEPS on percent;
 * 3. the matched field's display colour (effective field config incl. overrides); the step index
 *    comes from the field thresholds so the overlay can expose it as data-dmap-step.
 */
export function colorFor(
  value: number | undefined,
  percent: number | undefined,
  rule: RuleThresholds | undefined,
  display: DisplayValue | undefined,
  fieldThresholds: ThresholdsConfig | undefined,
  theme: GrafanaTheme2
): ColorResult {
  if (value === undefined || !Number.isFinite(value)) {
    return { color: noDataColor(theme), stepIndex: -1 };
  }
  if (rule) {
    const input = rule.mode === 'percent' && percent !== undefined ? percent : value;
    const idx = stepIndexOf(input, rule.steps);
    return { color: theme.visualization.getColorByName(rule.steps[idx][1]), stepIndex: idx };
  }
  if (percent !== undefined) {
    const idx = stepIndexOf(percent, DEFAULT_PERCENT_STEPS);
    return { color: theme.visualization.getColorByName(DEFAULT_PERCENT_STEPS[idx][1]), stepIndex: idx };
  }
  const steps = fieldSteps(fieldThresholds);
  const idx = steps ? stepIndexOf(value, steps) : 0;
  const color = display?.color ?? (steps ? theme.visualization.getColorByName(steps[idx][1]) : theme.visualization.getColorByName('green'));
  return { color, stepIndex: idx };
}

export function widthFor(percent: number | undefined, w: { min: number; max: number }): number {
  if (percent === undefined || !Number.isFinite(percent)) {
    return w.min;
  }
  const t = Math.min(1, Math.max(0, percent / 100));
  return w.min + (w.max - w.min) * t;
}
```

```ts
import { formattedValueToString } from '@grafana/data';
import { endpointScope } from '../adapter/portograph';
import type {
  BindContext, BindResult, CellMeta, CellPatch, HalfState, LinkRule, PatchMap, ReducerName, Rule,
  RuleThresholds, SeriesInfo, SeriesSelector, ShapeRule, ShapeState, SparklineState, TemplateScope,
} from '../types';
import { colorFor, noDataColor, widthFor } from './color';
import { reduceValues } from './reduce';
import { cellMatches } from './select';
import { findSeries } from './series';
import { resolveTemplate } from './template';

interface Effective {
  ruleNames: string[];
  link?: LinkRule;
  shape?: ShapeRule;
  reducer?: ReducerName;
  label?: string;
  thresholds?: RuleThresholds;
  url?: string;
  urlRule?: string;
}

/** Later rules override earlier ones per property. */
function merge(rules: Rule[], cell: CellMeta): Effective | undefined {
  const eff: Effective = { ruleNames: [] };
  for (const r of rules) {
    if (!cellMatches(r.select, cell)) {
      continue;
    }
    eff.ruleNames.push(r.name);
    if (r.link) {
      eff.link = { ...eff.link, ...r.link };
    }
    if (r.shape) {
      eff.shape = { ...eff.shape, ...r.shape };
    }
    if (r.reducer) {
      eff.reducer = r.reducer;
    }
    if (r.label !== undefined) {
      eff.label = r.label;
    }
    if (r.thresholds) {
      eff.thresholds = r.thresholds;
    }
    if (r.url !== undefined) {
      eff.url = r.url;
      eff.urlRule = r.name;
    }
  }
  return eff.ruleNames.length ? eff : undefined;
}

export function scopeFor(cell: CellMeta): TemplateScope {
  return {
    cell: { ...cell.attrs, id: cell.id, key: cell.key, label: cell.labelText },
    from: endpointScope(cell.from),
    to: endpointScope(cell.to),
  };
}

interface Resolved {
  status: 'ok' | 'nodata' | 'unbound';
  series?: SeriesInfo;
  value?: number;
  unresolved: string[];
}

function resolveSeries(sel: SeriesSelector, series: SeriesInfo[], scope: TemplateScope, reducer: ReducerName): Resolved {
  const f = findSeries(sel, series, scope);
  if (f.unresolved.length) {
    return { status: 'unbound', unresolved: f.unresolved };
  }
  if (!f.series) {
    return { status: 'nodata', unresolved: [] };
  }
  const value = reduceValues(f.series.values, reducer);
  return { status: value === undefined ? 'nodata' : 'ok', series: f.series, value, unresolved: [] };
}

function half(sel: SeriesSelector, capacity: number | undefined, eff: Effective, scope: TemplateScope, series: SeriesInfo[], ctx: BindContext): { state: HalfState; unresolved: string[] } {
  const r = resolveSeries(sel, series, scope, eff.reducer ?? 'last');
  if (r.status !== 'ok' || r.value === undefined || !r.series) {
    return {
      state: { status: r.status, color: noDataColor(ctx.theme), width: ctx.linkWidth.min, label: r.status === 'nodata' ? 'no data' : 'unbound', stepIndex: -1 },
      unresolved: r.unresolved,
    };
  }
  const percent = capacity ? (r.value / capacity) * 100 : undefined;
  const display = ctx.display(r.series, r.value);
  const { color, stepIndex } = colorFor(r.value, percent, eff.thresholds, display, r.series.field.config?.thresholds ?? ctx.fieldThresholds, ctx.theme);
  const tpl = eff.label ?? (percent === undefined ? '${value}' : '${value} · ${percent}');
  const labelScope: TemplateScope = { ...scope, labels: r.series.labels, value: formattedValueToString(display), percent: percent === undefined ? undefined : `${Math.round(percent)}%` };
  const label = resolveTemplate(tpl, labelScope);
  return {
    state: { status: 'ok', color, width: widthFor(percent, ctx.linkWidth), label: label.text, stepIndex, value: r.value, percent, display, series: r.series },
    unresolved: label.unresolved,
  };
}

const UNBOUND = (ctx: BindContext): HalfState => ({ status: 'unbound', color: noDataColor(ctx.theme), width: ctx.linkWidth.min, label: 'unbound', stepIndex: -1 });

function capacityOf(link: LinkRule, scope: TemplateScope): { capacity?: number; unresolved: string[] } {
  if (link.capacity === undefined) {
    return { unresolved: [] };
  }
  if (typeof link.capacity === 'number') {
    return { capacity: link.capacity, unresolved: [] };
  }
  const r = resolveTemplate(link.capacity, scope);
  if (r.unresolved.length) {
    return { unresolved: r.unresolved };
  }
  const n = Number(r.text);
  return Number.isFinite(n) && n > 0 ? { capacity: n, unresolved: [] } : { unresolved: [`capacity "${r.text}" is not a number`] };
}

function shape(sh: ShapeRule, eff: Effective, scope: TemplateScope, series: SeriesInfo[], ctx: BindContext): { state?: ShapeState; spark?: SparklineState; unresolved: string[] } {
  const unresolved: string[] = [];
  let state: ShapeState | undefined;
  const wantFill = sh.fill ?? (!sh.stroke && !sh.text);
  if (sh.series) {
    const r = resolveSeries(sh.series, series, scope, eff.reducer ?? 'last');
    unresolved.push(...r.unresolved);
    if (r.status === 'ok' && r.value !== undefined && r.series) {
      const display = ctx.display(r.series, r.value);
      const { color, stepIndex } = colorFor(r.value, undefined, eff.thresholds, display, r.series.field.config?.thresholds ?? ctx.fieldThresholds, ctx.theme);
      let text: string | undefined;
      if (sh.text) {
        const t = resolveTemplate(eff.label ?? '${value}', { ...scope, labels: r.series.labels, value: formattedValueToString(display) });
        unresolved.push(...t.unresolved);
        text = t.text;
      }
      state = { status: 'ok', color, fill: wantFill, stroke: !!sh.stroke, stepIndex, text, value: r.value, display, series: r.series };
    } else {
      state = { status: r.status, color: noDataColor(ctx.theme), fill: wantFill, stroke: !!sh.stroke, stepIndex: -1 };
    }
  }
  let spark: SparklineState | undefined;
  if (sh.sparkline) {
    const { position, ...sel } = sh.sparkline;
    const f = findSeries(sel, series, scope);
    unresolved.push(...f.unresolved);
    if (f.series && f.series.values.length) {
      spark = { values: f.series.values, color: state?.status === 'ok' ? state.color : ctx.theme.colors.text.secondary, position: position ?? 'bottom', series: f.series };
    }
  }
  return { state, spark, unresolved };
}

export function bind(rules: Rule[], cells: CellMeta[], series: SeriesInfo[], ctx: BindContext): BindResult {
  const patches: PatchMap = new Map();
  const warnings: string[] = [];
  for (const cell of cells) {
    const eff = merge(rules, cell);
    if (!eff) {
      continue;
    }
    const scope = scopeFor(cell);
    const patch: CellPatch = { cellId: cell.id, ruleNames: eff.ruleNames, scope, urls: [], warnings: [] };
    const unresolved: string[] = [];
    let primary: SeriesInfo | undefined;

    if (eff.link && (cell.isEdge || cell.kind === 'link')) {
      const cap = capacityOf(eff.link, scope);
      unresolved.push(...cap.unresolved);
      patch.link = {};
      if (cap.unresolved.length) {
        // spec: a template that does not resolve makes the binding unbound (grey, warning in edit mode)
        if (eff.link.a2b) {
          patch.link.a2b = UNBOUND(ctx);
        }
        if (eff.link.b2a) {
          patch.link.b2a = UNBOUND(ctx);
        }
      } else if (eff.link.a2b) {
        const h = half(eff.link.a2b, cap.capacity, eff, scope, series, ctx);
        patch.link.a2b = h.state;
        unresolved.push(...h.unresolved);
        primary = primary ?? h.state.series;
      }
      if (!cap.unresolved.length && eff.link.b2a) {
        const h = half(eff.link.b2a, cap.capacity, eff, scope, series, ctx);
        patch.link.b2a = h.state;
        unresolved.push(...h.unresolved);
        primary = primary ?? h.state.series;
      }
    }
    if (eff.shape && !cell.isEdge) {
      const s = shape(eff.shape, eff, scope, series, ctx);
      patch.shape = s.state;
      patch.sparkline = s.spark;
      unresolved.push(...s.unresolved);
      primary = primary ?? s.state?.series;
    }
    if (eff.url) {
      const u = resolveTemplate(eff.url, { ...scope, labels: primary?.labels ?? {} });
      unresolved.push(...u.unresolved);
      if (!u.unresolved.length) {
        patch.urls.push({ title: eff.urlRule ?? eff.ruleNames[eff.ruleNames.length - 1], url: u.text });
      }
    }
    if (unresolved.length) {
      const msg = `${eff.ruleNames.join('+')} / ${cell.id}: unresolved ${[...new Set(unresolved)].join(', ')}`;
      patch.warnings.push(msg);
      warnings.push(msg);
    }
    if (patch.link || patch.shape || patch.sparkline) {
      patches.set(cell.id, patch);
    }
  }
  return { patches, warnings };
}
```

- [ ] **Step 2: Implement `src/render/sanitize.ts`**

Two passes. Pass 1 (XML DOM): structural clean-up that DOMPurify does not do. Pass 2: DOMPurify in its default HTML parsing mode (the HTML parser fixes SVG camelCase tags such as `foreignObject` and `linearGradient` and parses the label HTML inside `foreignObject`), returning a DOM.

```ts
import DOMPurify from 'dompurify';

export interface SanitizeResult {
  svg: string;
  removed: { elements: number; attributes: number; images: number };
  foreignObjects: number;
  warnings: string[];
}

const SVG_NS = 'http://www.w3.org/2000/svg';

export function parseSvg(text: string): SVGSVGElement {
  const doc = new DOMParser().parseFromString(text, 'image/svg+xml');
  const root = doc.documentElement;
  if (!root || root.localName !== 'svg' || root.namespaceURI !== SVG_NS || doc.querySelector('parsererror')) {
    throw new Error('Not an SVG document');
  }
  return root as unknown as SVGSVGElement;
}

/** true when a CSS text references anything that is not a local #id */
function hasExternalUrl(cssText: string): boolean {
  if (/@import/i.test(cssText)) {
    return true;
  }
  const re = /url\(\s*['"]?([^'")]+)['"]?\s*\)/gi;
  let m: RegExpExecArray | null;
  while ((m = re.exec(cssText))) {
    if (!m[1].trim().startsWith('#')) {
      return true;
    }
  }
  return false;
}

const PURIFY_CONFIG: DOMPurify.Config = {
  USE_PROFILES: { svg: true, svgFilters: true, html: true },
  // DOMPurify forbids foreignObject by default; the spec keeps HTML labels. The html profile
  // sanitises their content; iframe/object/embed/script are forbidden below.
  ADD_TAGS: ['foreignObject', 'switch'],
  ADD_ATTR: ['data-cell-id', 'pointer-events', 'requiredFeatures', 'color-scheme', 'xml:space'],
  FORBID_TAGS: ['iframe', 'object', 'embed', 'script', 'form', 'input', 'button', 'textarea', 'select', 'link', 'meta', 'base', 'template', 'math', 'audio', 'video'],
  FORBID_ATTR: ['srcdoc', 'formaction', 'action', 'ping'],
  ADD_DATA_URI_TAGS: ['image'],
  ALLOW_DATA_ATTR: true,
  RETURN_DOM: true,
};

export function sanitizeSvg(text: string): SanitizeResult {
  const root = parseSvg(text);
  const removed = { elements: 0, attributes: 0, images: 0 };

  // Pass 1: structural.
  // draw.io 32 writes <switch><foreignObject>HTML</foreignObject><image href="data:image/png..."/></switch>;
  // browsers take the foreignObject branch, so the PNG is dead weight.
  for (const sw of Array.from(root.querySelectorAll('switch'))) {
    for (const child of Array.from(sw.children)) {
      if (child.localName === 'image') {
        child.remove();
        removed.images++;
      }
    }
  }
  root.removeAttribute('content'); // embedded copy of the diagram XML (xmlsvg export)
  for (const use of Array.from(root.querySelectorAll('use'))) {
    const href = use.getAttribute('href') ?? use.getAttribute('xlink:href') ?? '';
    if (!href.startsWith('#')) {
      use.remove();
      removed.elements++;
    }
  }
  for (const st of Array.from(root.querySelectorAll('style'))) {
    if (hasExternalUrl(st.textContent ?? '')) {
      st.remove();
      removed.elements++;
    }
  }
  for (const el of [root, ...Array.from(root.querySelectorAll('[style]'))]) {
    const style = el.getAttribute('style');
    if (style && hasExternalUrl(style)) {
      el.removeAttribute('style');
      removed.attributes++;
    }
  }

  // Pass 2: DOMPurify.
  const serialized = new XMLSerializer().serializeToString(root);
  const body = DOMPurify.sanitize(serialized, PURIFY_CONFIG) as unknown as HTMLElement;
  removed.elements += DOMPurify.removed.filter((r) => 'element' in r).length;
  removed.attributes += DOMPurify.removed.filter((r) => 'attribute' in r).length;
  const svg = body.querySelector('svg');
  if (!svg) {
    throw new Error('Not an SVG document');
  }
  const foreignObjects = svg.querySelectorAll('foreignObject').length;
  const warnings: string[] = [];
  if (foreignObjects) {
    warnings.push(`${foreignObjects} HTML labels (foreignObject). Set convertToSvg=1 on labels for smaller, native text.`);
  }
  return { svg: svg.outerHTML, removed, foreignObjects, warnings };
}
```

```ts
import { attachLinkLabels, cellMetaFromAttrs } from '../adapter/portograph';
import type { CellEntry, CellIndex, CellMeta } from '../types';

const SHAPE_TAGS = new Set(['rect', 'path', 'ellipse', 'circle', 'polygon', 'image']);

/**
 * Parse the sanitised SVG text (HTML serialisation from sanitizeSvg) and make it the only child
 * of the container. A <template> uses the HTML parser, which handles SVG foreign content and
 * the HTML inside foreignObject labels.
 */
export function mountSvg(container: HTMLElement, svgText: string): SVGSVGElement {
  const tpl = document.createElement('template');
  tpl.innerHTML = svgText;
  const root = tpl.content.querySelector('svg');
  if (!root) {
    throw new Error('Not an SVG document');
  }
  container.replaceChildren(root);
  root.style.display = 'block';
  return root;
}

/** True when `el` sits inside a nested cell group below `group`. */
function insideNestedCell(el: Element, group: Element): boolean {
  let p = el.parentElement;
  while (p && p !== group) {
    if (p.hasAttribute('data-cell-id')) {
      return true;
    }
    p = p.parentElement;
  }
  return false;
}

function ownDescendants(group: Element, selector: string): Element[] {
  return Array.from(group.querySelectorAll(selector)).filter((el) => !insideNestedCell(el, group));
}

function metaAttrs(group: Element): Record<string, string> {
  const attrs: Record<string, string> = {};
  for (const a of Array.from(group.attributes)) {
    if (a.name.startsWith('data-meta-')) {
      attrs[a.name.slice('data-meta-'.length)] = a.value;
    }
  }
  return attrs;
}

function labelOf(group: Element): { el?: Element; text: string } {
  const text = ownDescendants(group, 'text')[0];
  if (text) {
    return { el: text, text: (text.textContent ?? '').replace(/\s+/g, ' ').trim() };
  }
  const fo = ownDescendants(group, 'foreignObject')[0];
  if (fo) {
    return { el: fo, text: (fo.textContent ?? '').replace(/\s+/g, ' ').trim() };
  }
  return { text: '' };
}

export function buildCellIndex(root: SVGSVGElement): CellIndex {
  const index: CellIndex = new Map();
  for (const group of Array.from(root.querySelectorAll('g[data-cell-id]')) as SVGGElement[]) {
    const id = group.getAttribute('data-cell-id')!;
    const paths = ownDescendants(group, 'path') as SVGPathElement[];
    // draw.io edge polylines carry fill="none" AND pointer-events="stroke"; stencil outlines have fill="none" only.
    const line = paths.find((p) => p.getAttribute('fill') === 'none' && p.getAttribute('pointer-events') === 'stroke');
    const arrows = line ? paths.filter((p) => p !== line && p.getAttribute('pointer-events') === 'all') : [];
    let shape: SVGGraphicsElement | undefined;
    if (!line) {
      shape = ownDescendants(group, Array.from(SHAPE_TAGS).join(',')).find(
        (el) => SHAPE_TAGS.has(el.localName) && !el.closest('switch, foreignObject')
      ) as SVGGraphicsElement | undefined;
    }
    const label = labelOf(group);
    const meta = cellMetaFromAttrs(id, metaAttrs(group), !!line, label.text || undefined);
    const entry: CellEntry = {
      meta,
      group,
      shape,
      line,
      arrows,
      label: label.el,
      original: {
        fill: shape?.style.fill,
        stroke: shape?.style.stroke ?? line?.style.stroke,
        strokeWidth: line?.style.strokeWidth,
        text: label.text,
      },
    };
    index.set(id, entry);
  }
  attachLinkLabels(cellMetas(index));
  return index;
}

export function cellMetas(index: CellIndex): CellMeta[] {
  return Array.from(index.values(), (e) => e.meta);
}
```

```ts
import type { ZoomOptions } from '../types';

export interface ViewBox {
  x: number;
  y: number;
  w: number;
  h: number;
}

export interface Layout {
  viewBox: ViewBox;
  width: string;
  height: string;
  overflow: 'hidden' | 'auto';
}

export function readViewBox(root: SVGSVGElement): ViewBox {
  const vb = root.getAttribute('viewBox');
  if (vb) {
    const [x, y, w, h] = vb.trim().split(/[\s,]+/).map(Number);
    if ([x, y, w, h].every(Number.isFinite) && w > 0 && h > 0) {
      return { x, y, w, h };
    }
  }
  const w = parseFloat(root.getAttribute('width') ?? '0') || 100;
  const h = parseFloat(root.getAttribute('height') ?? '0') || 100;
  return { x: 0, y: 0, w, h };
}

export function viewBoxFor(zoom: ZoomOptions, base: ViewBox, box: { width: number; height: number }): Layout {
  switch (zoom.mode) {
    case 'fit':
      return { viewBox: base, width: '100%', height: '100%', overflow: 'hidden' };
    case 'fit-width': {
      const h = (box.width * base.h) / base.w;
      return { viewBox: base, width: `${box.width}px`, height: `${h}px`, overflow: 'auto' };
    }
    case 'original':
      return { viewBox: base, width: `${base.w}px`, height: `${base.h}px`, overflow: 'auto' };
    case 'custom': {
      const f = (zoom.percent || 100) / 100;
      return { viewBox: base, width: `${base.w * f}px`, height: `${base.h * f}px`, overflow: 'auto' };
    }
  }
}

/** Scale the viewBox by `factor` (<1 zooms in) around the point (cx, cy) in viewBox units. */
export function zoomAt(vb: ViewBox, factor: number, cx: number, cy: number): ViewBox {
  const w = vb.w * factor;
  const h = vb.h * factor;
  return { x: cx - (cx - vb.x) * factor, y: cy - (cy - vb.y) * factor, w, h };
}

/** Move the view by (dx, dy) in viewBox units: dragging right shows content further left. */
export function pan(vb: ViewBox, dx: number, dy: number): ViewBox {
  return { ...vb, x: vb.x - dx, y: vb.y - dy };
}

export function applyLayout(root: SVGSVGElement, layout: Layout): void {
  const { x, y, w, h } = layout.viewBox;
  root.setAttribute('viewBox', `${x} ${y} ${w} ${h}`);
  root.setAttribute('width', layout.width);
  root.setAttribute('height', layout.height);
  root.setAttribute('preserveAspectRatio', 'xMidYMid meet');
}

/** Client pixel to viewBox units. Uses getScreenCTM when the browser provides it. */
export function clientToViewBox(root: SVGSVGElement, clientX: number, clientY: number): { x: number; y: number } {
  const ctm = typeof root.getScreenCTM === 'function' ? root.getScreenCTM() : null;
  if (ctm) {
    const inv = ctm.inverse();
    return { x: inv.a * clientX + inv.c * clientY + inv.e, y: inv.b * clientX + inv.d * clientY + inv.f };
  }
  const r = root.getBoundingClientRect();
  const vb = readViewBox(root);
  return { x: vb.x + ((clientX - r.left) / (r.width || 1)) * vb.w, y: vb.y + ((clientY - r.top) / (r.height || 1)) * vb.h };
}
```

```ts
import type { CellEntry, CellIndex, CellPatch, PatchMap } from '../types';

function setText(label: Element | undefined, text: string): void {
  if (!label) {
    return;
  }
  if (label.localName === 'text') {
    const spans = label.querySelectorAll('tspan');
    if (spans.length) {
      spans[0].textContent = text;
      for (let i = 1; i < spans.length; i++) {
        spans[i].textContent = '';
      }
    } else {
      label.textContent = text;
    }
    return;
  }
  // foreignObject: write into the deepest element that holds text
  let el: Element = label;
  while (el.children.length === 1) {
    el = el.children[0];
  }
  el.textContent = text;
}

function applyShape(entry: CellEntry, patch: CellPatch): void {
  const s = patch.shape;
  if (!s) {
    return;
  }
  const shape = entry.shape as SVGElement | undefined;
  if (shape) {
    if (s.fill) {
      shape.style.fill = s.color;
    }
    if (s.stroke) {
      shape.style.stroke = s.color;
    }
  }
  if (s.text !== undefined) {
    setText(entry.label, s.text);
  }
}

function applyLink(entry: CellEntry, patch: CellPatch): void {
  const l = patch.link;
  if (!l || (!l.a2b && !l.b2a)) {
    return;
  }
  if (entry.line) {
    entry.line.style.strokeOpacity = '0';
  }
  for (const a of entry.arrows) {
    a.style.opacity = '0';
  }
}

function tag(entry: CellEntry, patch: CellPatch): void {
  const states = [patch.shape, patch.link?.a2b, patch.link?.b2a].filter(Boolean) as Array<{ status: string; stepIndex: number }>;
  if (!states.length) {
    return;
  }
  const status = states.some((s) => s.status === 'ok') ? 'ok' : states.some((s) => s.status === 'unbound') ? 'unbound' : 'nodata';
  const step = Math.max(...states.map((s) => s.stepIndex));
  entry.group.setAttribute('data-dmap-status', status);
  entry.group.setAttribute('data-dmap-step', String(step));
}

function reset(entry: CellEntry): void {
  const shape = entry.shape as SVGElement | undefined;
  if (shape) {
    shape.style.fill = entry.original.fill ?? '';
    shape.style.stroke = entry.original.stroke ?? '';
  }
  if (entry.line) {
    entry.line.style.strokeOpacity = '';
    entry.line.style.strokeWidth = entry.original.strokeWidth ?? '';
  }
  for (const a of entry.arrows) {
    a.style.opacity = '';
  }
  if (entry.original.text !== undefined && entry.label) {
    setText(entry.label, entry.original.text);
  }
  entry.group.removeAttribute('data-dmap-status');
  entry.group.removeAttribute('data-dmap-step');
}

/** Write patches into the SVG DOM. Returns the ids that are patched now. */
export function applyPatches(index: CellIndex, patches: PatchMap, previous: Set<string>): Set<string> {
  const done = new Set<string>();
  for (const id of previous) {
    if (!patches.has(id)) {
      const entry = index.get(id);
      if (entry) {
        reset(entry);
      }
    }
  }
  for (const [id, patch] of patches) {
    const entry = index.get(id);
    if (!entry) {
      continue;
    }
    if (previous.has(id)) {
      reset(entry);
    }
    applyShape(entry, patch);
    applyLink(entry, patch);
    tag(entry, patch);
    done.add(id);
  }
  return done;
}
```

```ts
export interface Point {
  x: number;
  y: number;
}

const ARGS: Record<string, number> = { M: 2, L: 2, H: 1, V: 1, Z: 0, C: 6, S: 4, Q: 4, T: 2, A: 7 };

/**
 * Vertices of an SVG path. Lines are exact; curves contribute their end point only
 * (draw.io orthogonal edges with rounded=0 are pure M/L). Pure, so jsdom tests work without getPointAtLength.
 */
export function parsePathPoints(d: string): Point[] {
  const tokens = d.match(/[MLHVZCSQTAmlhvzcsqta]|-?\d*\.?\d+(?:e[-+]?\d+)?/g);
  if (!tokens) {
    return [];
  }
  const pts: Point[] = [];
  let cmd = '';
  let i = 0;
  let cur: Point = { x: 0, y: 0 };
  let start: Point = { x: 0, y: 0 };
  const num = () => Number(tokens[i++]);
  while (i < tokens.length) {
    const t = tokens[i];
    if (/[a-zA-Z]/.test(t)) {
      cmd = t;
      i++;
      if (cmd.toUpperCase() === 'Z') {
        cur = { ...start };
        pts.push(cur);
        continue;
      }
    }
    const upper = cmd.toUpperCase();
    const rel = cmd !== upper;
    const n = ARGS[upper];
    if (n === undefined || i + n > tokens.length) {
      break;
    }
    const a: number[] = [];
    for (let k = 0; k < n; k++) {
      a.push(num());
    }
    let next: Point;
    switch (upper) {
      case 'H':
        next = { x: rel ? cur.x + a[0] : a[0], y: cur.y };
        break;
      case 'V':
        next = { x: cur.x, y: rel ? cur.y + a[0] : a[0] };
        break;
      default: {
        const ex = a[n - 2];
        const ey = a[n - 1];
        next = { x: rel ? cur.x + ex : ex, y: rel ? cur.y + ey : ey };
      }
    }
    if (upper === 'M') {
      start = next;
      if (rel) {
        cmd = 'l';
      } else {
        cmd = 'L';
      }
    }
    cur = next;
    pts.push(cur);
  }
  return pts;
}

export function polylineLength(pts: Point[]): number {
  let l = 0;
  for (let i = 1; i < pts.length; i++) {
    l += Math.hypot(pts[i].x - pts[i - 1].x, pts[i].y - pts[i - 1].y);
  }
  return l;
}

export function pointAt(pts: Point[], dist: number): { x: number; y: number; angle: number } {
  if (pts.length === 1) {
    return { ...pts[0], angle: 0 };
  }
  let acc = 0;
  for (let i = 1; i < pts.length; i++) {
    const a = pts[i - 1];
    const b = pts[i];
    const seg = Math.hypot(b.x - a.x, b.y - a.y);
    const angle = Math.atan2(b.y - a.y, b.x - a.x);
    if (dist <= acc + seg || i === pts.length - 1) {
      const t = seg === 0 ? 0 : Math.min(1, Math.max(0, (dist - acc) / seg));
      return { x: a.x + (b.x - a.x) * t, y: a.y + (b.y - a.y) * t, angle };
    }
    acc += seg;
  }
  return { ...pts[pts.length - 1], angle: 0 };
}

/** Sub-polyline between two arc-length positions. */
export function slicePolyline(pts: Point[], from: number, to: number): Point[] {
  const out: Point[] = [pointAt(pts, from)].map(({ x, y }) => ({ x, y }));
  let acc = 0;
  for (let i = 1; i < pts.length; i++) {
    const seg = Math.hypot(pts[i].x - pts[i - 1].x, pts[i].y - pts[i - 1].y);
    acc += seg;
    if (acc > from && acc < to) {
      out.push(pts[i]);
    }
  }
  const end = pointAt(pts, to);
  out.push({ x: end.x, y: end.y });
  return out;
}

/* ---------- affine matrices (plain objects; no DOMMatrix so jsdom tests work) ---------- */

export interface Matrix {
  a: number;
  b: number;
  c: number;
  d: number;
  e: number;
  f: number;
}

export const IDENTITY: Matrix = { a: 1, b: 0, c: 0, d: 1, e: 0, f: 0 };

export function multiply(m: Matrix, n: Matrix): Matrix {
  return {
    a: m.a * n.a + m.c * n.b,
    b: m.b * n.a + m.d * n.b,
    c: m.a * n.c + m.c * n.d,
    d: m.b * n.c + m.d * n.d,
    e: m.a * n.e + m.c * n.f + m.e,
    f: m.b * n.e + m.d * n.f + m.f,
  };
}

export function invert(m: Matrix): Matrix {
  const det = m.a * m.d - m.b * m.c || 1;
  return {
    a: m.d / det,
    b: -m.b / det,
    c: -m.c / det,
    d: m.a / det,
    e: (m.c * m.f - m.d * m.e) / det,
    f: (m.b * m.e - m.a * m.f) / det,
  };
}

export function applyMatrix(m: Matrix, p: Point): Point {
  return { x: m.a * p.x + m.c * p.y + m.e, y: m.b * p.x + m.d * p.y + m.f };
}

/* ---------- path geometry: browser API first, parsed polyline as fallback ---------- */

export interface PathGeom {
  /** arc length in the path's own user units */
  length: number;
  /** point and tangent angle at arc length d, in `target` coordinates */
  pointAt(d: number): { x: number; y: number; angle: number };
  /** sampled points between two arc lengths, in `target` coordinates */
  polyline(from: number, to: number): Point[];
}

type PathApi = SVGPathElement & { getTotalLength(): number; getPointAtLength(d: number): { x: number; y: number } };

/**
 * Geometry of an edge path expressed in the coordinate system of `target` (the overlay group).
 * Browser: getTotalLength/getPointAtLength on the real path, points mapped with
 * target.getCTM()^-1 × line.getCTM(), so transforms on the edge or its ancestors are respected.
 * jsdom: pure parser on the d attribute (M/L exact, curves approximated); identity transform.
 */
export function pathGeometry(line: SVGPathElement, target: SVGGraphicsElement): PathGeom {
  const api = line as PathApi;
  const hasApi = typeof api.getTotalLength === 'function' && typeof api.getPointAtLength === 'function' && typeof line.getCTM === 'function';
  if (!hasApi) {
    const pts = parsePathPoints(line.getAttribute('d') ?? '');
    return {
      length: polylineLength(pts),
      pointAt: (d) => pointAt(pts, d),
      polyline: (from, to) => slicePolyline(pts, from, to),
    };
  }
  const toM = (m: Matrix | null | undefined): Matrix => (m ? { a: m.a, b: m.b, c: m.c, d: m.d, e: m.e, f: m.f } : IDENTITY);
  const M = multiply(invert(toM(target.getCTM())), toM(line.getCTM()));
  const length = api.getTotalLength();
  const clamp = (d: number) => Math.min(length, Math.max(0, d));
  const at = (d: number): Point => {
    const p = api.getPointAtLength(clamp(d));
    return applyMatrix(M, { x: p.x, y: p.y });
  };
  return {
    length,
    pointAt(d) {
      const p = at(d);
      const fwd = at(d + 0.5);
      const back = at(d - 0.5);
      return { x: p.x, y: p.y, angle: Math.atan2(fwd.y - back.y, fwd.x - back.x) };
    },
    polyline(from, to) {
      const n = Math.max(2, Math.ceil(Math.abs(to - from) / 4));
      const out: Point[] = [];
      for (let i = 0; i <= n; i++) {
        out.push(at(from + ((to - from) * i) / n));
      }
      return out;
    },
  };
}
```

```ts
import type { GrafanaTheme2 } from '@grafana/data';
import type { CellEntry, CellIndex, HalfState, PatchMap, SparklineState } from '../types';
import { parsePathPoints, PathGeom, pathGeometry, Point } from './geometry';

export const OVERLAY_CLASS = 'dmap-overlay';
const NS = 'http://www.w3.org/2000/svg';

export interface OverlayOptions {
  theme: GrafanaTheme2;
  fontSize?: number;
  labelOffset?: number;
  arrowSize?: number;
  sparkHeight?: number;
}

export function ensureOverlay(root: SVGSVGElement): SVGGElement {
  let g = root.querySelector(`:scope > g.${OVERLAY_CLASS}`) as SVGGElement | null;
  if (!g) {
    g = document.createElementNS(NS, 'g');
    g.setAttribute('class', OVERLAY_CLASS);
    g.setAttribute('pointer-events', 'visiblePainted');
    root.appendChild(g);
  }
  return g;
}

function el<K extends keyof SVGElementTagNameMap>(tag: K, attrs: Record<string, string | number>): SVGElementTagNameMap[K] {
  const e = document.createElementNS(NS, tag);
  for (const [k, v] of Object.entries(attrs)) {
    e.setAttribute(k, String(v));
  }
  return e;
}

const fmt = (n: number) => String(Math.round(n * 100) / 100);
const pointsAttr = (pts: Point[]) => pts.map((p) => `${fmt(p.x)},${fmt(p.y)}`).join(' ');

function drawHalf(layer: SVGGElement, cellId: string, which: 'a2b' | 'b2a', geo: PathGeom, pts: Point[], state: HalfState, arrowAt: number, forward: boolean, labelAt: number, o: Required<OverlayOptions>): void {
  layer.appendChild(
    el('polyline', {
      class: 'dmap-half',
      'data-dmap-cell': cellId,
      'data-dmap-half': which,
      'data-dmap-status': state.status,
      'data-dmap-step': state.stepIndex,
      points: pointsAttr(pts),
      fill: 'none',
      stroke: state.color,
      'stroke-width': state.width,
      'stroke-linecap': 'butt',
      'stroke-linejoin': 'round',
      'pointer-events': 'stroke',
    })
  );
  const tip = geo.pointAt(arrowAt);
  const ang = forward ? tip.angle : tip.angle + Math.PI;
  const s = o.arrowSize;
  const tri: Point[] = [
    { x: tip.x, y: tip.y },
    { x: tip.x - s * Math.cos(ang) + (s / 2) * Math.sin(ang), y: tip.y - s * Math.sin(ang) - (s / 2) * Math.cos(ang) },
    { x: tip.x - s * Math.cos(ang) - (s / 2) * Math.sin(ang), y: tip.y - s * Math.sin(ang) + (s / 2) * Math.cos(ang) },
  ];
  layer.appendChild(el('polygon', { class: 'dmap-arrow', 'data-dmap-cell': cellId, 'data-dmap-half': which, points: pointsAttr(tri), fill: state.color, 'pointer-events': 'none' }));

  const lp = geo.pointAt(labelAt);
  const nx = -Math.sin(lp.angle);
  const ny = Math.cos(lp.angle);
  const cx = lp.x + nx * o.labelOffset;
  const cy = lp.y + ny * o.labelOffset;
  const w = state.label.length * o.fontSize * 0.6 + 8;
  const h = o.fontSize + 6;
  const g = el('g', { class: 'dmap-label', 'data-dmap-cell': cellId, 'data-dmap-half': which, 'pointer-events': 'none' });
  g.appendChild(el('rect', { x: cx - w / 2, y: cy - h / 2, width: w, height: h, rx: 3, fill: o.theme.colors.background.primary, stroke: state.color, 'stroke-width': 1 }));
  const text = el('text', { x: cx, y: cy, 'text-anchor': 'middle', 'dominant-baseline': 'central', 'font-size': o.fontSize, 'font-family': o.theme.typography.fontFamily, fill: o.theme.colors.text.primary });
  text.textContent = state.label;
  g.appendChild(text);
  layer.appendChild(g);
}

function drawLink(layer: SVGGElement, entry: CellEntry, link: { a2b?: HalfState; b2a?: HalfState }, o: Required<OverlayOptions>): void {
  if (!entry.line) {
    return;
  }
  const geo = pathGeometry(entry.line, layer);
  const L = geo.length;
  if (!(L > 0)) {
    return;
  }
  const id = entry.meta.id;
  if (link.a2b && link.b2a) {
    drawHalf(layer, id, 'a2b', geo, geo.polyline(0, L / 2), link.a2b, L / 2, true, L / 4, o);
    drawHalf(layer, id, 'b2a', geo, geo.polyline(L / 2, L), link.b2a, L / 2, false, (3 * L) / 4, o);
    return;
  }
  if (link.a2b) {
    drawHalf(layer, id, 'a2b', geo, geo.polyline(0, L), link.a2b, L, true, L / 2, o);
  } else if (link.b2a) {
    drawHalf(layer, id, 'b2a', geo, geo.polyline(0, L), link.b2a, 0, false, L / 2, o);
  }
}

/** Bounding box in the shape's own user units. getBBox when the browser has it, else attributes or path points. */
export function bboxOf(shape: SVGGraphicsElement): { x: number; y: number; w: number; h: number } | undefined {
  if (typeof shape.getBBox === 'function') {
    try {
      const b = shape.getBBox();
      if (b.width > 0 || b.height > 0) {
        return { x: b.x, y: b.y, w: b.width, h: b.height };
      }
    } catch {
      /* detached element */
    }
  }
  const num = (n: string) => parseFloat(shape.getAttribute(n) ?? '');
  if (shape.localName === 'rect' || shape.localName === 'image') {
    return { x: num('x') || 0, y: num('y') || 0, w: num('width'), h: num('height') };
  }
  if (shape.localName === 'ellipse' || shape.localName === 'circle') {
    const rx = num('rx') || num('r');
    const ry = num('ry') || num('r');
    return { x: num('cx') - rx, y: num('cy') - ry, w: 2 * rx, h: 2 * ry };
  }
  const pts = parsePathPoints(shape.getAttribute('d') ?? shape.getAttribute('points')?.replace(/[, ]+/g, ' ').replace(/^/, 'M ') ?? '');
  if (!pts.length) {
    return undefined;
  }
  const xs = pts.map((p) => p.x);
  const ys = pts.map((p) => p.y);
  return { x: Math.min(...xs), y: Math.min(...ys), w: Math.max(...xs) - Math.min(...xs), h: Math.max(...ys) - Math.min(...ys) };
}

function drawSparkline(layer: SVGGElement, entry: CellEntry, s: SparklineState, o: Required<OverlayOptions>): void {
  if (!entry.shape || s.values.length < 2) {
    return;
  }
  const b = bboxOf(entry.shape);
  if (!b) {
    return;
  }
  const H = o.sparkHeight;
  const box =
    s.position === 'top' ? { x: b.x, y: b.y - H - 2, w: b.w, h: H } : s.position === 'inside' ? { x: b.x + 2, y: b.y + b.h - H - 2, w: b.w - 4, h: H } : { x: b.x, y: b.y + b.h + 2, w: b.w, h: H };
  const vals = s.values.filter((v) => Number.isFinite(v));
  const min = Math.min(...vals);
  const max = Math.max(...vals);
  const span = max - min || 1;
  const pts = s.values.map((v, i) => ({ x: box.x + (i / (s.values.length - 1)) * box.w, y: box.y + box.h - ((Number.isFinite(v) ? v - min : 0) / span) * box.h }));
  layer.appendChild(el('polyline', { class: 'dmap-spark', 'data-dmap-cell': entry.meta.id, points: pointsAttr(pts), fill: 'none', stroke: s.color, 'stroke-width': 1.5, 'pointer-events': 'none' }));
}

export function renderOverlay(root: SVGSVGElement, index: CellIndex, patches: PatchMap, opts: OverlayOptions): void {
  const o: Required<OverlayOptions> = { fontSize: 10, labelOffset: 11, arrowSize: 8, sparkHeight: 14, ...opts };
  const layer = ensureOverlay(root);
  layer.replaceChildren();
  for (const [id, patch] of patches) {
    const entry = index.get(id);
    if (!entry) {
      continue;
    }
    if (patch.link) {
      drawLink(layer, entry, patch.link, o);
    }
    if (patch.sparkline) {
      drawSparkline(layer, entry, patch.sparkline, o);
    }
  }
}
```

```ts
export function decodeDataUri(uri: string): string {
  const m = /^data:([^,]*?)(;base64)?,(.*)$/s.exec(uri);
  if (!m) {
    return uri;
  }
  if (m[2]) {
    const bin = atob(m[3]);
    const bytes = Uint8Array.from(bin, (c) => c.charCodeAt(0));
    return new TextDecoder('utf-8').decode(bytes);
  }
  return decodeURIComponent(m[3]);
}
```

```ts
import { decodeDataUri } from './decode';

/** Required embed parameters. A parameter already present in the configured URL wins (for example ui=sketch). */
export const EMBED_PARAMS: Record<string, string> = {
  embed: '1',
  proto: 'json',
  configure: '1',
  spin: '1',
  libraries: '1',
  ui: 'min',
  saveAndExit: '1',
  noExitBtn: '0',
};

export function buildEditorUrl(base: string, isDark = false): string {
  const u = new URL(base);
  for (const [k, v] of Object.entries(EMBED_PARAMS)) {
    if (!u.searchParams.has(k)) {
      u.searchParams.set(k, v);
    }
  }
  u.searchParams.set('dark', isDark ? '1' : '0');
  return u.toString();
}

export function editorOrigin(base: string): string {
  return new URL(base).origin;
}

export interface EditorMessage {
  event: string;
  xml?: string;
  data?: string;
  format?: string;
  exit?: boolean;
  modified?: boolean;
}

export type EditorAction =
  | { action: 'configure'; config: Record<string, unknown> }
  | { action: 'load'; xml: string; autosave: 0 | 1; title?: string; modified?: string; saveAndExit?: string; noSaveBtn?: string; noExitBtn?: string; dark?: boolean }
  | { action: 'export'; format: 'xmlsvg'; embedCellMetadata: boolean; embedImages: boolean; theme: 'auto'; spin?: string }
  | { action: 'exit' };

export interface ProtocolState {
  phase: 'init' | 'loaded' | 'exporting' | 'done';
  xml: string;
  pendingExit: boolean;
}

export interface Step {
  state: ProtocolState;
  send: EditorAction[];
  result?: { xml: string; svg: string };
  close: boolean;
}

export interface ProtocolOptions {
  mode: 'edit' | 'export-only';
  title?: string;
  isDark: boolean;
}

export function initialState(xml: string): ProtocolState {
  return { phase: 'init', xml, pendingExit: false };
}

export function parseMessage(data: unknown): EditorMessage | undefined {
  if (typeof data !== 'string' || !data.startsWith('{')) {
    return undefined;
  }
  try {
    const obj = JSON.parse(data);
    return obj && typeof obj.event === 'string' ? (obj as EditorMessage) : undefined;
  } catch {
    return undefined;
  }
}

const EXPORT: EditorAction = { action: 'export', format: 'xmlsvg', embedCellMetadata: true, embedImages: true, theme: 'auto', spin: 'Saving' };

export function handleMessage(state: ProtocolState, msg: EditorMessage, opts: ProtocolOptions): Step {
  const noop: Step = { state, send: [], close: false };
  switch (msg.event) {
    case 'configure':
      return { ...noop, send: [{ action: 'configure', config: { compressXml: false, defaultAdaptiveColors: 'auto', autosaveDelay: 0 } }] };
    case 'init': {
      const load: EditorAction = {
        action: 'load',
        xml: state.xml,
        autosave: 0,
        title: opts.title,
        modified: 'unsavedChanges',
        saveAndExit: '1',
        dark: opts.isDark,
        ...(opts.mode === 'export-only' ? { noSaveBtn: '1', noExitBtn: '1' } : {}),
      };
      return { ...noop, send: [load] };
    }
    case 'load':
      if (opts.mode === 'export-only') {
        return { state: { ...state, phase: 'exporting', pendingExit: true }, send: [EXPORT], close: false };
      }
      return { ...noop, state: { ...state, phase: 'loaded' } };
    case 'save':
      return { state: { phase: 'exporting', xml: msg.xml ?? state.xml, pendingExit: !!msg.exit }, send: [EXPORT], close: false };
    case 'export': {
      if (state.phase !== 'exporting' || !msg.data) {
        return noop;
      }
      const svg = decodeDataUri(msg.data);
      const xml = msg.xml ?? state.xml;
      const close = state.pendingExit || opts.mode === 'export-only';
      return { state: { phase: close ? 'done' : 'loaded', xml, pendingExit: false }, send: [], result: { xml, svg }, close };
    }
    case 'exit':
      return { state: { ...state, phase: 'done' }, send: [], close: true };
    default:
      return noop;
  }
}
```

```ts
import type { CellPatch, PatchMap } from '../types';

/** The nearest patched cell at or above `target`. Overlay elements point at their cell with data-dmap-cell. */
export function patchAt(target: EventTarget | null, stop: Element, patches: PatchMap): CellPatch | undefined {
  let el = target instanceof Element ? target : null;
  while (el && el !== stop) {
    const id = el.getAttribute('data-dmap-cell') ?? el.getAttribute('data-cell-id');
    if (id) {
      const p = patches.get(id);
      if (p) {
        return p;
      }
    }
    el = el.parentElement;
  }
  return undefined;
}
```

```ts
import type { DisplayValue, LinkModel, ScopedVars } from '@grafana/data';
import type { BindStatus, CellPatch, SeriesInfo } from '../types';

export interface Primary {
  status: BindStatus;
  series?: SeriesInfo;
  display?: DisplayValue;
  value?: number;
  percent?: number;
  label?: string;
}

export function primaryOf(patch: CellPatch): Primary {
  const h = patch.link?.a2b ?? patch.link?.b2a;
  if (h) {
    return { status: h.status, series: h.series, display: h.display, value: h.value, percent: h.percent, label: h.label };
  }
  const s = patch.shape;
  if (s) {
    return { status: s.status, series: s.series, display: s.display, value: s.value, label: s.text };
  }
  return { status: 'nodata' };
}

export function buildScopedVars(patch: CellPatch, primary: Primary): ScopedVars {
  const vars: ScopedVars = {
    cell: { text: 'cell', value: patch.scope.cell },
  };
  if (patch.scope.from) {
    vars.from = { text: 'from', value: patch.scope.from };
  }
  if (patch.scope.to) {
    vars.to = { text: 'to', value: patch.scope.to };
  }
  if (primary.series) {
    vars.__series = { text: 'Series', value: { name: primary.series.name, refId: primary.series.refId } };
    vars.__field = { text: 'Field', value: { name: primary.series.field.name, labels: primary.series.labels } };
  }
  if (primary.display) {
    vars.__value = { text: 'Value', value: { raw: primary.value, numeric: primary.display.numeric, text: primary.display.text } };
  }
  return vars;
}

export function resolveLinks(patch: CellPatch, primary: Primary, replaceVariables: (s: string, v?: ScopedVars) => string): LinkModel[] {
  const vars = buildScopedVars(patch, primary);
  const out: LinkModel[] = patch.urls.map((u) => ({
    title: u.title,
    href: replaceVariables(u.url, vars),
    target: '_blank',
    origin: patch,
  }));
  const field = primary.series?.field;
  if (field?.getLinks) {
    const row = Math.max(0, (primary.series?.values.length ?? 1) - 1);
    out.push(...field.getLinks({ valueRowIndex: row, calculatedValue: primary.display }));
  }
  return out;
}
```

```ts
/** Normalise pasted or uploaded draw.io content to an <mxfile> string. */
export function importDiagram(text: string): { xml: string; warnings: string[] } {
  const t = text.trim();
  const warnings: string[] = [];
  if (t.startsWith('<svg') || (t.startsWith('<?xml') && t.includes('<svg'))) {
    const m = /\scontent="([^"]*)"/.exec(t);
    if (!m) {
      throw new Error('This SVG has no embedded draw.io diagram. Export it with "Include a copy of my diagram".');
    }
    const ta = document.createElement('textarea');
    ta.innerHTML = m[1];
    return importDiagram(ta.value);
  }
  if (t.startsWith('<mxGraphModel')) {
    return { xml: `<mxfile><diagram id="page-1" name="Page-1">${t}</diagram></mxfile>`, warnings };
  }
  if (t.includes('<mxfile')) {
    const pages = (t.match(/<diagram[\s>]/g) ?? []).length;
    if (pages > 1) {
      warnings.push(`${pages} pages found. The panel renders page 1 only.`);
    }
    return { xml: t, warnings };
  }
  throw new Error('Not a draw.io file. Paste the XML from Extras > Edit Diagram or upload a .drawio file.');
}
```

```ts
import { useLayoutEffect, useRef, useState } from 'react';
import { sanitizeSvg } from '../render/sanitize';
import { buildCellIndex, mountSvg } from '../render/svgStage';
import { readViewBox, ViewBox } from '../render/zoom';
import type { CellIndex } from '../types';

export interface Stage {
  index: CellIndex;
  root?: SVGSVGElement;
  base?: ViewBox;
  warnings: string[];
  error?: string;
}

/** Mount the SVG once per hash and build the cell index. */
export function useStage(containerRef: React.RefObject<HTMLDivElement>, svg: string | undefined, hash: string | undefined): Stage {
  const [stage, setStage] = useState<Stage>({ index: new Map(), warnings: [] });
  const lastHash = useRef<string>();
  useLayoutEffect(() => {
    const el = containerRef.current;
    if (!el) {
      return;
    }
    if (!svg) {
      el.replaceChildren();
      lastHash.current = undefined;
      setStage({ index: new Map(), warnings: [] });
      return;
    }
    if (hash && hash === lastHash.current) {
      return;
    }
    try {
      const clean = sanitizeSvg(svg);
      const root = mountSvg(el, clean.svg);
      const index = buildCellIndex(root);
      lastHash.current = hash;
      setStage({ index, root, base: readViewBox(root), warnings: clean.warnings });
    } catch (e) {
      setStage({ index: new Map(), warnings: [], error: (e as Error).message });
    }
  }, [containerRef, svg, hash]);
  return stage;
}
```

```tsx
import { applyPatches } from '../render/applier';
import { renderOverlay } from '../render/overlay';
import { cellMetas } from '../render/svgStage';
import { applyLayout, clientToViewBox, pan, viewBoxFor, ViewBox, zoomAt } from '../render/zoom';
import { CellPatch, DEFAULT_OPTIONS, Options, SeriesInfo } from '../types';
import { useStage } from './useStage';

const styles = {
  wrapper: css`
    position: relative;
    width: 100%;
    height: 100%;
  `,
  stage: css`
    width: 100%;
    height: 100%;
    & > svg {
      display: block;
    }
  `,
  empty: css`
    display: flex;
    align-items: center;
    justify-content: center;
    height: 100%;
    opacity: 0.7;
  `,
  badge: css`
    position: absolute;
    right: 4px;
    top: 4px;
    font-size: 11px;
    padding: 1px 6px;
    border-radius: 3px;
    z-index: 1;
  `,
};

interface MenuState {
  x: number;
  y: number;
  links: LinkModel[];
}

export function DrawioMapPanel({ options, data, width, height, fieldConfig, replaceVariables, timeZone }: PanelProps<Options>) {
  const theme = useTheme2();
  const opts = { ...DEFAULT_OPTIONS, ...options, zoom: { ...DEFAULT_OPTIONS.zoom, ...options.zoom }, linkWidth: { ...DEFAULT_OPTIONS.linkWidth, ...options.linkWidth } };
  const containerRef = useRef<HTMLDivElement>(null);
  const stage = useStage(containerRef, opts.diagram?.svg, opts.diagram?.hash);
  const patchedRef = useRef<Set<string>>(new Set());
  const [menu, setMenu] = useState<MenuState | null>(null);
  const [hover, setHover] = useState<{ x: number; y: number; patch: CellPatch } | null>(null);
  const [view, setView] = useState<ViewBox | null>(null);

  const series = useMemo(() => extractSeries(data.series), [data.series]);
  // Grafana attaches field.display (effective config incl. overrides) to panel data; fall back for tests.
  const display = useCallback(
    (s: SeriesInfo, v: number) => (s.field.display ?? getDisplayProcessor({ field: s.field, theme, timeZone }))(v),
    [theme, timeZone]
  );
  const result = useMemo(
    () =>
      bind(opts.rules ?? [], cellMetas(stage.index), series, {
        theme,
        fieldThresholds: fieldConfig.defaults.thresholds,
        replaceVariables,
        display,
        linkWidth: opts.linkWidth,
      }),
    // eslint-disable-next-line react-hooks/exhaustive-deps
    [opts.rules, stage.index, series, theme, fieldConfig.defaults.thresholds, replaceVariables, display, opts.linkWidth.min, opts.linkWidth.max]
  );

  // Apply patches and redraw the overlay once per frame.
  useEffect(() => {
    if (!stage.root) {
      return;
    }
    const root = stage.root;
    const id = requestAnimationFrame(() => {
      patchedRef.current = applyPatches(stage.index, result.patches, patchedRef.current);
      renderOverlay(root, stage.index, result.patches, { theme });
    });
    return () => cancelAnimationFrame(id);
  }, [stage.root, stage.index, result, theme]);

  // Zoom layout.
  useEffect(() => {
    if (!stage.root || !stage.base) {
      return;
    }
    const layout = viewBoxFor(opts.zoom, view ?? stage.base, { width, height });
    applyLayout(stage.root, layout);
    if (containerRef.current) {
      containerRef.current.style.overflow = layout.overflow;
    }
  }, [stage.root, stage.base, opts.zoom.mode, opts.zoom.percent, width, height, view]);

  // Reset the custom view and close the menu when the diagram changes.
  useEffect(() => {
    setView(null);
    setMenu(null);
  }, [opts.diagram?.hash]);

  const onClick = (e: React.MouseEvent) => {
    const wrapper = containerRef.current;
    const patch = wrapper ? patchAt(e.target, wrapper, result.patches) : undefined;
    if (!patch) {
      setMenu(null);
      return;
    }
    // Resolve the links first, then open the menu with them in state: the first click must show the right items.
    const links = resolveLinks(patch, primaryOf(patch), replaceVariables);
    setMenu(links.length ? { x: e.clientX, y: e.clientY, links } : null);
  };
  const onWheel = (e: React.WheelEvent) => {
    if (!opts.zoom.wheel || !stage.root) {
      return;
    }
    e.preventDefault();
    const c = clientToViewBox(stage.root, e.clientX, e.clientY);
    setView((v) => zoomAt(v ?? stage.base!, e.deltaY > 0 ? 1.1 : 1 / 1.1, c.x, c.y));
  };
  const drag = useRef<{ x: number; y: number } | null>(null);
  const onMouseDown = (e: React.MouseEvent) => {
    if (opts.zoom.pan && stage.root) {
      drag.current = clientToViewBox(stage.root, e.clientX, e.clientY);
    }
  };
  const onMouseMove = (e: React.MouseEvent) => {
    if (drag.current && stage.root) {
      const c = clientToViewBox(stage.root, e.clientX, e.clientY);
      const d = drag.current;
      setView((v) => pan(v ?? stage.base!, c.x - d.x, c.y - d.y));
      return;
    }
    const wrapper = containerRef.current;
    if (!wrapper) {
      return;
    }
    const patch = patchAt(e.target, wrapper, result.patches);
    if (!patch) {
      setHover(null);
      return;
    }
    const r = wrapper.getBoundingClientRect();
    setHover({ x: e.clientX - r.left, y: e.clientY - r.top, patch });
  };
  const onMouseUp = () => (drag.current = null);

  if (!opts.diagram?.svg) {
    return (
      <div className={styles.empty} data-testid="dmap-empty">
        No diagram. Edit the panel and open the draw.io editor or import a .drawio file.
      </div>
    );
  }

  const warnings = [...stage.warnings, ...result.warnings];

  return (
    <div
      className={styles.wrapper}
      data-testid="dmap-panel"
      data-dmap-cells={stage.index.size}
      data-dmap-patched={result.patches.size}
      data-dmap-warnings={warnings.length}
      data-dmap-hash={opts.diagram.hash}
      style={{ colorScheme: theme.isDark ? 'dark' : 'light' }}
      onClick={onClick}
      onWheel={onWheel}
      onMouseDown={onMouseDown}
      onMouseMove={onMouseMove}
      onMouseUp={onMouseUp}
      onMouseLeave={() => {
        setHover(null);
        drag.current = null;
      }}
    >
      <div ref={containerRef} className={styles.stage} />
      {stage.error ? <div className={styles.empty}>{stage.error}</div> : null}
      {warnings.length ? (
        <div className={styles.badge} style={{ background: theme.colors.warning.main, color: theme.colors.warning.contrastText }} title={warnings.join('\n')} data-testid="dmap-warning-badge">
          {warnings.length} warning{warnings.length > 1 ? 's' : ''}
        </div>
      ) : null}
      {hover && !menu ? <Tooltip x={hover.x} y={hover.y} patch={hover.patch} width={width} height={height} /> : null}
      {menu ? (
        <ContextMenu
          x={menu.x}
          y={menu.y}
          onClose={() => setMenu(null)}
          renderMenuItems={() =>
            menu.links.map((l, i) => (
              <MenuItem key={`${i}-${l.href}`} label={l.title} url={l.href} target={l.target} onClick={l.onClick ? (ev) => l.onClick!(ev) : undefined} />
            ))
          }
        />
      ) : null}
    </div>
  );
}
```

`ContextMenu` and `MenuItem` are stable exports of `@grafana/ui` since 8.x (verify in `node_modules/@grafana/ui/dist/index.d.ts`; `MenuItem` renders an `<a role="menuitem" href>` when `url` is set). `DataLinksContextMenu` is not used: it needs a React child per clickable element, and our cells are raw SVG DOM, so it cannot hold the links for the first click. The links are computed into state before the menu renders.

```ts
/**
 * Builds provisioning/dashboards/drawiomap-demo.json from the template, the demo rules
 * and the l3-routing fixture. Run: npm run build:dashboard
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { resolve } from 'node:path';
import { JSDOM } from 'jsdom';

const root = process.cwd(); // npm scripts run from the repo root
const dom = new JSDOM('');
// DOMPurify picks up `window` when its module loads, so set the globals before the dynamic imports.
Object.assign(globalThis, {
  window: dom.window,
  document: dom.window.document,
  DOMParser: dom.window.DOMParser,
  XMLSerializer: dom.window.XMLSerializer,
  Node: dom.window.Node,
  Element: dom.window.Element,
});

const PANELS = [
  { id: 1, svg: 'fixtures/svg/l3-routing.svg', xml: 'fixtures/portograph/l3-routing.drawio', rules: 'demo/rules.yaml' },
  { id: 2, svg: 'fixtures/svg/hand-drawn.svg', xml: 'fixtures/hand/hand-drawn.drawio', rules: 'demo/rules-hand.yaml' },
];

async function main() {
  const { sanitizeSvg } = await import('../src/render/sanitize');
  const { parseRulesYaml } = await import('../src/rules/schema');
  const { fnv1a } = await import('../src/util/hash');

  const dashboard = JSON.parse(readFileSync(resolve(root, 'demo/dashboard.template.json'), 'utf8'));
  for (const spec of PANELS) {
    const svgRaw = readFileSync(resolve(root, spec.svg), 'utf8');
    const xml = readFileSync(resolve(root, spec.xml), 'utf8');
    const rules = parseRulesYaml(readFileSync(resolve(root, spec.rules), 'utf8'));
    if (!rules.rules) {
      throw new Error(`${spec.rules}: ${rules.errors.join('; ')}`);
    }
    const clean = sanitizeSvg(svgRaw);
    const panel = dashboard.panels.find((p: { id: number }) => p.id === spec.id);
    panel.options.rules = rules.rules;
    panel.options.diagram = { xml, svg: clean.svg, hash: fnv1a(clean.svg + xml), updatedAt: '2026-10-17T00:00:00.000Z' };
    console.log(`panel ${spec.id}: svg ${Math.round(clean.svg.length / 1024)} KB (from ${Math.round(svgRaw.length / 1024)} KB), ${rules.rules.length} rules`);
  }
  const out = resolve(root, 'provisioning/dashboards/drawiomap-demo.json');
  writeFileSync(out, JSON.stringify(dashboard, null, 2) + '\n');
  console.log(out);
}

main().catch((e) => {
  console.error(e);
  process.exit(1);
});
```

```bash
#!/usr/bin/env bash
# Spec section 6 item 6: view mode must load no draw.io scripts.
# The importer legitimately parses <mxGraphModel>, so do not grep for "mxGraph". Check instead:
#  1. no draw.io / maxGraph package in the dependency tree,
#  2. no draw.io runtime globals in dist/module.js (GraphViewer, mxClient, viewer-static, @maxgraph),
#  3. the bundle stays small,
#  4. @grafana/react-detect finds no React 19 breakers.
# The runtime check (no request to the editor origin in view mode) is tests/no-drawio.spec.ts.
set -euo pipefail
root=$(cd "$(dirname "$0")/.." && pwd)
f="$root/dist/module.js"
[ -f "$f" ] || { echo "run npm run build first"; exit 1; }
bad=0
deps=$(node -e 'const p=require(process.argv[1]); console.log(Object.keys({...p.dependencies,...p.devDependencies}).join("\n"))' "$root/package.json")
for pkg in @maxgraph/core mxgraph drawio @drawio/mcp; do
  if printf '%s\n' "$deps" | grep -qx "$pkg"; then
    echo "FAIL: dependency $pkg is a draw.io runtime"
    bad=1
  fi
done
if npm ls @maxgraph/core mxgraph 2>/dev/null | grep -qE '@maxgraph/core@|mxgraph@'; then
  echo "FAIL: transitive maxGraph/mxGraph package"
  bad=1
fi
for token in GraphViewer mxClient viewer-static '@maxgraph' 'maxgraph/core'; do
  if grep -q -- "$token" "$f"; then
    echo "FAIL: $token found in dist/module.js"
    bad=1
  fi
done
size=$(wc -c <"$f")
echo "dist/module.js: $size bytes"
if [ "$size" -gt 400000 ]; then
  echo "FAIL: bundle larger than 400 KB"
  bad=1
fi
npx -y @grafana/react-detect@latest
[ "$bad" -eq 0 ] && echo "bundle OK"
exit $bad
```

```ts
test('edit mode opens the self-hosted draw.io editor, saves, and the panel updates', async ({ gotoPanelEditPage, page }) => {

  const box = (await canvas.boundingBox())!;
```
