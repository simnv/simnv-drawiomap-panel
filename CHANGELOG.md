# Changelog

## 1.0.0 (Unreleased)

Initial release.

- Removed the rules of version 1 (the `rules` option and the Legacy rules editor). A saved value loads; the panel ignores it and shows one warning. See README, "Rules of version 1".
- A shape binding colours the node icon, the shape or its outline by the value (`shape.target`), with the colours of the field config. Before, a version 2 shape binding gave the label text only.
